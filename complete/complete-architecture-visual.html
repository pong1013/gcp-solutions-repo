    Complete Tradeoff
    完整治理與審計

    每個 pipeline 階段都留下 manifest、audit table、quality result 或 Composer task status，讓 production 問題可追查。

    可重跑的營運介面

    Composer DAG 顯示 dependency、logs 和 failed task，operator 可以針對單一步驟重跑，而不是整條 nightly pipeline 重來。

    品質閘門阻擋 activation

    Dataplex scans 和 Dataform assertions 把壞資料擋在 ML scoring 與 Salesforce push 前，避免 campaign activation 擴大錯誤。

    可交付 deployment template

    Terraform remote state、Cloud Build CI/CD、Flex Template build、DAG import 和 Cloud Run image update 讓方案可 review、可重建。

    完成度提醒：complete 是治理最完整、成本最高的方向。Salesforce Cloud Run Job 支援 dry-run 與正式 push path，但 DAG 預設會跳過正式寫入；要真正寫 Salesforce，必須明確設定 `skip_salesforce_write=false`、提供 Campaign ID、放入 Salesforce secrets，並確認 quality gate 已通過。Dataform SQLX 已在 repo 內，production workflow 仍需確保 code 已同步/commit 到 Dataform repository。
