Business Output

    可監控與可重跑

    Cloud Composer 將原本黑盒 VM scripts 拆成可觀察 task，失敗時可從特定 Data Fusion pipeline、DQ 或 archive task 重跑。

    資料分層與治理

    BigQuery raw、staging、curated、mart 讓來源追蹤、清洗、分析和 activation 各有邊界，raw/staging 套 730 天保留策略。

    品質閘門與 evidence

    DQ SQL 會檢查 row count、required keys、identity match、email/consent 與數值範圍，錯誤列寫入 rejected records 並透過 Pub/Sub 通知。

    從 migration 到 business value

    資料通過品質檢查後可產生 user features、BigQuery ML segments 與 Salesforce campaign audience，讓搬遷後的平台直接支援行銷啟動。
