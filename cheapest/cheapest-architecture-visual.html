Cheapest GCP Architecture

用 serverless 與 batch primitives 做最低固定成本 CRM migration

Cheapest 方案刻意避開 Composer、Data Fusion、Dataflow、Dataplex 等較高固定成本服務；CRM CSV 交給 GCS + BigQuery load jobs，排程和重跑交給 Scheduler + Workflows，長任務和 Salesforce smoke test 放到 Cloud Run Jobs。

Cost Positioning

不用常駐 Airflow 或 low-code ETL runtime，靠 pay-per-use 的 Workflows、BigQuery jobs、Cloud Run Jobs 控制固定成本。

Core Stack

Cloud Storage、Datastream、Cloud Scheduler、Workflows、BigQuery、Cloud Run Jobs、Secret Manager、Cloud Build。

Operational Surface

Workflows execution history 加上 `audit.pipeline_step_status` 與 `audit.quality_check_results`，取代 Composer dashboard。

Honest Status

Salesforce Cloud Run Job 已能 dry-run 和寫 audit；真正 Campaign Member write 尚未啟用。

    Cheapest Tradeoff
    低固定成本

    不用 Composer 或 Data Fusion 常駐環境，夜間批次靠 Workflows、BigQuery jobs 和 Cloud Run Jobs 在需要時才產生成本。

    批次處理夠直接

    CRM CSV 用 BigQuery load jobs 載入 raw tables，SQL 在 BigQuery 內完成 staging、curated、mart 和 quality checks。

    最低可接受營運性

    Workflows execution history 搭配 audit tables 提供 dashboard 資料和 rerun contract，雖然不像 Airflow 細緻，但成本更低。

    Activation 謹慎落地

    Salesforce job 目前做 OAuth、audience count 和 audit dry run；真正寫 Campaign Member 前仍需補 mapping 與 idempotent upsert。

    完成度提醒：cheapest 是「低成本但不砍 Oracle CDC」。Datastream 保留；省成本的是不用 Data Fusion、Composer、Dataflow、Dataplex。Cloud Run Salesforce job 目前 `SALESFORCE_DRY_RUN=true`，不要把 dry run 說成 production write 已完成。
